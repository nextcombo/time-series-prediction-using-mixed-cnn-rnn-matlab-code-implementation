# Time Series Prediction Using Mixed CNN - RNN (Matlab Code Implementation)

This example aims to propose the concept of combining Convolutional Neural Networks (CNN) with Recurrent Neural Networks (RNN) to predict the number of chickenpox cases based on the previous months. 
The CNN is an excellent network for feature extraction, while RNN has proven its ability to predict sequence-to-sequence values. At each time step, the CNN extracts the main features of the sequence, while the RNN learns to predict the next value at the next time step.
